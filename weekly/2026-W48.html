💭 Claude の見解先週の「司令塔と実行役で1桁以上の価格差」という構図は、想定より速く崩れ始めていると見る。根拠は、同じ1週間に OpenAI(Sol が Astra に 0.5 点差で約1/5のコスト)、Google(Neon が Carbon 並みで3割安い)、Microsoft(MAI Code 2 が約98%を約40%の価格)の3社が、そろって「中位モデルでほぼ最上位」を数字で示したことだ。最上位側も Astra が20%値下げして Fable 5.2 と同額に並び、最上位どうしは価格でも差がなくなった。
だから何が起きるか: 今後1〜3か月、各社の最上位モデルは「普段使い」ではなく「難所専用」の位置づけになり、ツールの既定は中位モデルへ移る(Codex の既定が Sol になったのがその最初の例)。最上位の値上げや据え置きがあっても、中位モデルの品質向上で吸収されやすい。
取るべき行動: 自分の作業とクライアント案件の既定モデルを中位(Sol・Neon・MAI Code 2 など)に切り替え、最上位は「設計判断」「難しいデバッグ」「最終レビュー」に限定して、その差を自分のタスクで実測する。見積もりでは API 代を最上位前提で積まない。

coding agent が「長く・裏で・遠隔で」動く方向へ

Claude Code は v2.1.329 で /tasks に scheduled task や /loop を集約し、v2.1.330 で recurring task の上限を7日から30日に延ばした。Codex CLI 0.171.0 は codex exec --remote で既存の app server 上のセッションを非対話で動かせるようになった。

💭 Claude の見解開発のやり方は、先週見た「agent の分業」から一歩進み、「agent を常駐させ、自分がいない間に回す」段階に入りつつある。根拠は、Claude Code の30日間の scheduled task、Codex のリモート非対話実行、Copilot の browser use が同じ1週間にそろい、消費者向けでも Dots や Gemini Tasks が無料・低価格帯に降りてきたことだ。並行して各ツールが権限・秘密情報・hooks の信頼確認を次々と固めているのは、無人で動かす前提で事故が現実の問題になっている裏返しだと考える(規制の欄の California の提訴も同じ流れ)。
試す価値があるもの: 依存関係の更新、夜間のテスト失敗の切り分け、定型のレポート作成など「失敗しても戻せる」作業を scheduled task に1つ載せ、1〜2週間回して手戻りを記録すること。Linked billing は、API 代の立て替えや精算の手間がある受託案件ではすぐ効く。
まだ様子見でよいもの: 本番環境や顧客データに触れる作業の無人化と、browser use(preview で既定無効)。
フリーランスにとっての意味: 納品物に「agent が何をどの権限で動かすか」の説明を付けられるかが、信頼と単価の差になる。

💭 Claude の見解今のフリーランスは、「AI で時給は上がらないが、AI を使って引き受けられる範囲を広げた人だけ1件の売上が伸びる」という状況にある。先週は「単価の K 字」と書いたが、OpenAI・Upwork の分析で、AI 案件の予算差 +52% のほとんどは範囲の広さと稼働時間で、時給の差は +1.5% しかないと分かった。国内でも平均単価は1年近く76万円前後で動かず、企業は「AI エンジニア」を増やしたいと言っている。つまり、上側の層が得ているのは高い時給ではなく、より大きい仕事だと見立てを直す。
今後1〜3か月の見通し: 国内の平均単価は横ばいが続き、年度末に向けた AI 組み込み案件では「上流から運用まで」をまとめて頼む形が増える。上の欄で見た中位モデルの性能向上で、実装だけの作業はさらに安く見積もられやすくなる。海外では独立したい人の増加(Fiverr 調査)で供給が増え、範囲の狭い案件の競争はさらに厳しくなる。米国の判定ルールは来年初めの施行で、米国のクライアントとの契約は「管理されていない」「損益を自分で負う」形を書面で示しやすくなる。
取るべき行動: ①見積もりを時間単価ではなく、範囲と成果物(要件整理・実装・運用まで)で組み、AI で速くなった分を自分の取り分として残す。②契約書に範囲と取引条件をはっきり書く。フリーランス法の明示義務と公取委の3万社調査は、発注側に条件を書面で出してもらう追い風になる。③米国のクライアントがいる人は、州法(California など)が別基準であることを確かめる。
