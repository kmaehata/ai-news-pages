新モデル・新製品の動き

Anthropic が Claude Fable 5.2 / Mythos 5.2 を公開(11/9)

Fable 5.2 は全ユーザー・主要クラウドで提供。価格は入力 $8・出力 $40(1M tokens あたり)、fast mode はその2倍。
Mythos 5.2 は同じモデルからサイバー・生物の安全装置を外した版で、審査を通った組織だけが使える。
小さいモデルに助言したり仕事を振ったりする advisor / orchestrator の役割や、1,000超の subagent の協調を打ち出した。

Google が Gemini 4 Carbon を一般の有料開発者に開放(11/10)、続いて Gemini 4 Hydrogen を公開(11/12)

Carbon は 10/28 にまずサイバー防御の組織などに限定で出し、11/10 に Gemini API の有料枠へ広げた。価格は 11/30 まで入力 $2・出力 $10、12/1 から $4・$20 に上がると報じられている(報道ベース)。
Hydrogen は Gemini 3.8 Flash の後継にあたる日常の coding・agent 向けの安価なモデル。Google の開発者向け記事では、Antigravity の Orchestrator が Carbon と Hydrogen を組み合わせて使うと説明している。

3社以外: Mistral Large 4 の weights 公開(10/29)、Meta Muse Ember(11/9)、Qwen4-Max の一般提供(11/16)

Mistral Large 4 は 1T パラメータの MoE で、Hugging Face で weights を公開。ただし他社にサービスとして提供する場合は別途の商用契約が必要なライセンス。
Meta の Muse Ember は入力 $0.10・出力 $0.50 の低価格モデルで、大きいモデルが計画し Ember が大量の手順をこなす使い方を想定(報道ベース)。
Qwen4-Max は前世代よりタスク当たりコスト6割超減とされる(デイリーで既報)。

期間中の OpenAI の発表は、画像生成の Images 2.6(11/4)、ChatGPT の Businesses(11/10)や Wallet(11/13)など、製品・提携が中心だった。一次情報で日付を確かめられる一般向けの新しい主力モデルは見つからなかった。

💭 Claude の見解競争の軸は「最高性能」から「役割ごとの値付け」に移ったと見る。根拠は、Fable 5.2 が advisor / orchestrator を売りにし、Google は Carbon と Hydrogen を組み合わせる前提で出し、Meta も Ember を「大きいモデルの下で働く実行役」と位置づけた点だ。最上位は $8/$40(Fable)や 12/1 以降 $4/$20(Carbon)と高く、実行役は $0.10〜$1.50 程度と、1桁以上の価格差がついている。
だから何が起きるか: 案件で「Claude 固定」「Gemini 固定」の作りは、今後3か月で割高になりやすい。計画とレビューだけを上位モデルに任せ、実装・テスト実行は安いモデルに回す構成が標準になる。
取るべき行動: 自分の開発環境とクライアント向けの仕組みの両方で、モデル名を設定で差し替えられるようにしておく。Carbon を使っている案件は、12/1 の値上げ前に見積もりを見直す。

開発手法・ツール

「司令塔と実行役」の分業が各社のツールに組み込まれた

Google Antigravity の Orchestrator は Carbon と Hydrogen を1つの作業の中で使い分ける。Anthropic は Fable 5.2 で、小さいモデルへの助言・委任と、多数の subagent の協調を前面に出した。
Claude Code v2.1.326 では agent teams と Code Mode を同時に使えるようになった(デイリーで既報)。

ソースを開く ↗

Fable 5.2 の effort レベルと fast mode

effort は Low〜Max の段階で、Claude アプリと Claude Code の既定は Medium。同じ effort なら 5.1 よりトークンが少なくなったとしている。
fast mode は最大2.5倍速く、価格は2倍。

agent の plugin 形式を各ツールでそろえる動き(様子見)

Agent Plugins 1.0 という共通の plugin 形式を、GitHub Copilot・Codex・Cursor などが読み込めるという整理が出ている。project の .agents/skills/ を共通で読む流れもある(報道ベース、各社の一次情報では未確認)。

ソースを開く ↗
💭 Claude の見解開発のやり方は「1つの agent に頼む」から「agent の分業を設計する」に変わりつつある。根拠は、Google・Anthropic・Meta の3社が同じ3週間で、計画役と実行役を分ける構成を自社のツールやモデルの説明の中心に置いたことだ。
試す価値があるもの: 自分のリポジトリで、計画とレビューを上位モデル、実装とテストを安いモデルに分けて1週間回し、タスク当たりのコストと手戻りの回数を記録すること。Fable 5.2 の effort を Medium と High で比べ、どこから質が頭打ちになるかを測るのも安く試せる。
まだ様子見でよいもの: 1,000 subagent 規模の協調(個人の案件の規模では管理の手間が勝つ)と、plugin 形式の統一(一次情報がそろうまで待つ)。
フリーランスにとっての意味: 「コードを書ける」より「agent の分業を設計し、出力を検証できる」ことが単価の差になる。この経験を、数字付きで実績に書けるようにしておくとよい。
確度: 中

ベンチマーク・注目論文

Fable 5.2 の自社発表の数字: Remote Labor Index が 17.9% → 41.3%

前の版 Fable 5.1 との比較で、FrontierSWE v2 は 56.3% → 69.9%、OSWorld 2.1 は 83.5% → 89.3%、Remote Labor Index は 17.9% → 41.3%。
ただし AutomationBench では Gemini 4 Carbon(53.9%)が Fable 5.2(51.4%)を上回ると、Anthropic 自身が載せている。

Gemini 4 Hydrogen は Terminal-Bench 4.1 で 57%(Gemini 3.8 Flash は 18.2%)

安いモデルの層でも、ターミナル操作を伴う agent の作業の点数が3倍に上がったと報じられている(報道ベース)。

ソースを開く ↗
💭 Claude の見解いちばん実務に効く数字は、Remote Labor Index が1世代で2倍以上になったことだと考える。このベンチマークは、実際に外注されたリモートの仕事をどれだけ最後まで仕上げられるかを測るもので、まさにフリーランスが受けている種類の仕事だ。41% はまだ半分に届かないが、「定型の小口案件を丸ごと任せる」ことが現実の選択肢に入ってきたことを意味する。
一方で注意点もある。各社が FrontierSWE v2、Terminal-Bench 4.1 など、自分で選んだ新しいベンチマークで比べるようになり、横並びの比較がしにくくなった。どれも自社発表なので、案件で使うモデルは、自分の実際のタスクを10件ほど用意して自分で比べるのが確実だ。
安いモデルの層で agent の点数が大きく上がった(Hydrogen の 18.2% → 57%)ことも、上の「実行役は安いモデルに回す」構成を後押しする。
確度: 中

Upwork 第3四半期決算: AI スキルを持つ人材の取引が前年比 +55%(11/2)

売上は $185.6M、純利益 $31.8M。AI スキルを持つフリーランスの取引額(GSV)は前年比55%増、年換算で約 $450M。

一方で、Google 検索の変化と AI アシスタントへの移行で、新規顧客の集客が弱まっていると指摘された(報道ベース)。

国内: 生成 AI 案件の平均単価は月89万円、単価は K 字に二極化

フリーコンシェルジュの集計では、AI / 生成 AI の案件は 830 件、平均単価は月89万円、中央値85万円(11/6時点、募集終了分を含む)。
同じ運営元の分析では、AI 関連の案件数は1年で約2倍になった一方、高単価と低単価の差が広がっているとしている。集計方法は各社で違うため、数字は目安(報道ベース)。

🇯🇵 国内

国内: 連合「フリーランスとして働く人の意識・実態調査2026」(10/30)

フリーランス 1,000 人が対象。「将来への展望がある」は 23.4% で、2023年の調査から 11.9 ポイント下がった。生成 AI の影響も調べている(報道ベース)。

ソースを開く ↗
💭 Claude の見解今のフリーランスは、「AI を前提に仕事を設計できる人」と「AI に置き換えられる小口作業を売る人」に、はっきり二極化した状況にある。根拠は、同じ期間の決算で Upwork の AI スキル人材の取引が +55% だった一方、小口案件中心の Fiverr は購入者数が 25.8% 減ったこと。国内でも生成 AI 案件の平均が月89万円と全体の相場より高く、単価の K 字化が指摘されている。連合の調査で将来展望が大きく下がったのも、下側の層の不安を映していると考える。
今後1〜3か月の見通し: 国内は年度末に向けて「既存システムへの AI 組み込み」の案件が増え、上側の単価は保たれる。一方、仕様の決まった実装だけの案件は、上で見た Remote Labor Index の伸びもあり、単価の下押しが続く。海外プラットフォームでは、AI agent が人材を探す経路(Upwork の MCP など)が広がり、検索で見つけてもらう前提が崩れていく。
取るべき行動: ①職務経歴に「AI agent を使った開発で何がどれだけ速く・安くなったか」を数字で書く。②実装だけの案件より、要件整理・設計・レビューまで含む契約形を提案する。③海外プラットフォームを使うなら、プロフィールを agent が読み取りやすい具体的な書き方(スキル・実績・料金を明記)にしておく。
確度: 中
