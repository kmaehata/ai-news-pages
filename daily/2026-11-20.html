OpenAI が ChatGPT for Accounting を公開(報道ベース)

11/18〜19 に公開。請求書の作成、銀行照合、月次レポート、仕訳入力、監査準備などを行う Accounting plugin と、QuickBooks・Xero・Oracle NetSuite・BILL・FreshBooks などとの連携をまとめて提供する。
対象は ChatGPT の Business / Enterprise 系プラン。Enterprise では管理者の承認が必要で、税務・規制関連の提出物は人が確認する前提。業種別の「ChatGPT for X」展開の一環。

開発手法・ツール

Claude Code v2.1.328

11/18(米国時間)公開。Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude apps gateway 上の Opus 4.6 / Sonnet 4.6 で auto mode が使えるようになり、permission mode 未指定の対話セッションは auto mode で始まる。
/code-review はバグと CLAUDE.md 違反だけを Important / Pre-existing / Nit に分けて報告する形になり、スタイルや再利用の指摘は /simplify に移った。mcp_tool hook に "onFailure": "block" を追加。anyOf / oneOf / allOf で始まる schema の MCP tool が消える不具合なども修正。
