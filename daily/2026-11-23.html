Claude と作った Riemann 予想の Lean 証明を Lean FRO・Mathlib が「正しい」と認定

11/21(UTC)に Lean FRO と Mathlib Initiative が共同声明を出した。Anthropic の数学者 Levent Alpöge は 11/20 に、Claude と一緒に作った Riemann 予想の証明を約1700万行の Lean ライブラリとして公開しており、コミュニティが1日かけて確かめた。
確かめ方: 定理の主張を Mathlib を import するだけの別ファイルに切り出し、comparator と con-leche という独立した2つのツールで、ライブラリが証明した定理が Mathlib の Riemann 予想の主張と一致することを確認した。
制約: 人が読める解説は無く、AI が書いた説明は25万ページを超えるという(報道ベース)。声明自身も、証明がなぜ成り立つかの理解は今後の数学者の仕事だとしている。Clay 研究所はまだ未解決扱いで、計算資源のコストも公表されていない。AI が最難関級の未解決問題で形式検証つきの証明に届いた例として、エンジニアにも形式検証と agent の組み合わせの力を示す出来事。
