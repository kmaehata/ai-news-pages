OpenAI / Anthropic / Google

Anthropic が Claude Ship を公開、PR のレビュー・CI 修正・承認判断を agent が担当(beta)

11/23 公開。GitHub の pull request を「レビュー → 修正 → 承認判断」まで通す仕組みで、3つの agent からなる。Code Review(GA、Quick・Standard・Deep の3段階)、PR Steward(beta。失敗した CI・merge conflict・レビュー指摘に対応して push し、変更内容と戻し方をコメントする。承認・merge はしない)、Claude Approvals(beta。repo に置いたポリシーファイルに沿って定型的な変更を承認するか、人の承認を求める。まず observe-only で始めることを推奨)。
対象は Claude Team・Enterprise の GitHub repo。ZDR・HIPAA 構成・顧客管理鍵の組織は使えない。課金は token 量で、Code Review と PR Steward には管理者が上限を設定できる。開発者は Claude Code・desktop app の /ship(11/23 から順次)で、push から PR 作成・レビュー・修正までを一度に任せられる。「書く」から「出荷する」までを agent に寄せる流れの具体例。

その他のモデル発表

Z.ai が GLM-5.4 を Coding Plan で先行提供、初の Loop Transformer 採用の旗艦モデル

11/23(JST 13時台)に Z.ai の Zixuan Li が公表。GLM Coding Plan の全利用者が使え、画像入力(vision)とコーディング性能の向上が売り。週の利用枠は GLM-5.3 より50%多い。Claude Code からは glm-5.4[1m] を指定して使える。
Z.ai によると、層を繰り返し使う Loop Transformer を採用した初の旗艦モデルで、約750B 規模・28層を2回通す構成と報じられている(報道ベース)。通常の API は安全性評価のあと、open weight は安全対策のあとに公開する予定。公開時点でベンチマークは出ておらず、性能は未検証。

Claude Code v2.1.331

11/23 公開。Code Mode が Bedrock・Google Cloud Agent Platform・Microsoft Foundry・Claude Platform on AWS のターミナルでも使えるようになった。claude doctor に API 接続チェック、圧縮応答を切ってしまう proxy 向けの CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION、plugin の optionalDependencies を追加。
修正: 壊れた応答で MCP ツール呼び出しが最大30分止まる問題、rewind 失敗時にファイルが消える問題など。注意点: 管理対象の marketplace は 11/30 以降、既定で自動更新になる("autoUpdate": false で無効化)。Windows では HKLM のレジストリ設定が managed-settings.json より優先されるようになった。

🌏 海外

OpenAI が OpenWorks を開始、地域の AI 専門家に月最大 $8,000 を払い中小企業を無償支援

11/23(米国時間)発表。技術を持つ個人や小さなチーム(AI・ソフトウェアのコンサルも可)を「OpenWorks Partner」として採用し、月最大 $8,000 の stipend とツール・ワークショップの支援を出す。Partner は毎月一定日数を地元の中小企業の支援にあて、月1回ワークショップを開く。支援を受ける企業は無料で、ChatGPT Business を3か月無償で使える。
対象は独立系の米国中小企業で、SaaS・VC 出資・PE 傘下の企業は除外。まず米国20地域で試行する。AI 導入支援を「フリーランスの仕事」として大手 AI 企業が直接お金を出す形で、AI 導入コンサルの需要と相場感を示す動き。必要な稼働日数と支給期間はページに明記されていない。
