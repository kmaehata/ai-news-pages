OpenAI が GPT-6.2 Astra と GPT-6.2 Sol を公開

11/17(米国時間)に公開。Astra が最上位、Sol が普段使い向けの効率型。ChatGPT Work と Codex(Plus / Pro / Enterprise / Edu から順次)と API(gpt-6.2-astra / gpt-6.2-sol)で使える。
API 価格は 1M tokens あたり Astra が入力 $8・出力 $40(GPT-6 Astra から約20%減)、Sol は $2 / $10 で据え置き。context は約1.05M tokens(報道ベース)。Preparedness Framework で cyber 能力を「Critical」と評価し、safeguard を強めて出している。

Microsoft が Ignite で MAI Code 2 など自社モデル群を発表

11/17(米国時間)の Ignite で、MAI Code 2 / Code 2 Flash、MAI Cyber 2 Flash、MAI Image 2.7、音声対話の MAI Realtime 1 などを発表。MAI Code 2 は GitHub Copilot で一般提供。

開発手法・ツール

Claude API に Linked billing(beta)

11/17、自分のアプリの Claude 利用料を、利用者側の Claude 組織に払ってもらえるようになった。/v1/messages と /v1/chat/completions のリクエストごとに billing_policy で支払い元を選ぶ。
beta header は user-profiles-billing-2026-10-01。対象は Anthropic に直接 API 料金を払っている組織。利用者は Console で上限設定や連携解除ができる。
