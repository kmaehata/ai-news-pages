Claude の artifact を Mac・Windows アプリとして入れられる「Install as app」(beta)

11/24 公開。Claude for Mac・Windows で artifact を開き、Share メニューから「Install as app」を選ぶと、専用のアイコンとウィンドウを持つデスクトップアプリになる。Claude とコネクタを使え、元の artifact を直すとアプリも自動で更新される。利用量はプランの上限に数えられる。
権限は3段階で、既定はブラウザ版と同じ範囲。許可すると通知・グローバルショートカット・常に手前表示などが使え、自分か自組織が作ったアプリに限り「Full computer access」(プログラム実行やファイル変更)も付けられる。更新のたびに権限を聞き直す。Anthropic はアプリを事前審査しない。
全プランで beta。Team は既定で有効(Full access は無効)、Enterprise は owner が有効にするまで無効。HIPAA 対応組織とハイブリッド構成は対象外。Docs・Slides・Sheets はアプリ化できない。

OpenAI と Cisco が Shirudo を open source で公開、agent が書く eBPF の「盾」でパッチ前の脆弱性を防ぐ

11/23 発表。Cisco の Isovalent(Tetragon の開発元)が作った Linux 向けセキュリティ基盤で、AI agent が一時的な eBPF プログラム(shield)を書き、動いている kernel 上で攻撃経路を塞ぐ。恒久パッチができるまで再起動なしで守るのが狙い。デモでは Codex が作った shield が、稼働中の Elasticsearch への Java4Shell 攻撃を止めた。shield は本番投入前に人が確認する前提(報道ベース)。
リポジトリは github.com/shirudo-dev/shirudo、ライセンスは BSD-2-Clause。現状は pre-release で、本番には shirudo 用のパッチを当てた kernel と TPM 2.0 が要る。AI で脆弱性の発見が速くなった分、防御側も agent でパッチまでの空白を埋める方向の一例。

Claude API: Opus 4.5 の提供終了を告知(2027/1/22)、ZDR を最上位モデルで使える EFS を beta 公開

11/23 のリリースノート。claude-opus-4-5(claude-opus-4-5-20251101)を deprecated にし、Claude API での提供終了日を 2027/1/22 とした。移行先は Claude Opus 5.5 で、移行ガイドあり。他のクラウドでの日付は Model deprecations のページで確認する。
あわせて Enterprise Frontier Safeguards(EFS)を beta 公開。Claude Platform、Claude Platform on AWS、Google Cloud 上の Claude(Anthropic 管理)で、最上位モデルを Zero Data Retention で使える。prompt と応答は Anthropic が保持せず、暗号化した Sealed Safety Data を自社クラウドの bucket に置く。その bucket の日次チェック失敗・回復を知らせる webhook(external_storage.failed / recovered)も追加。

Codex CLI 0.172.0

11/24 公開。TUI でスラッシュコマンドの引数を Tab 補完できるようになり、agent command center では Shift+↑↓ でタスクグループを移動できる。ツール一覧をキャッシュ済みの任意の stdio MCP サーバーは、最初のツール呼び出しまで起動しないのが既定になった。接続アプリのツールごとに承認役(reviewer)を config.toml で指定でき、app-server のクライアントは Amazon Bedrock Runtime を選べる。
修正: codex exec resume が保存済みの sandbox 権限と作業ディレクトリを復元するように。Code Mode は host との接続をすべて gRPC にし、code_mode_host_grpc 設定は非推奨。
