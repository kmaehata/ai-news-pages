Alibaba Qwen4-Max が API で一般提供

11/11 からの限定 preview を経て、11/16 に QwenCloud で一般公開(model ID は qwen4-max)。新しい MoE アーキテクチャ、native vision、1M token の context を持つ。
Qwen3.8-Max と比べてタスク当たりのコストは60%超減とされる(Alibaba 自身の比較)。価格は入力 $1.50、出力 $4.50(1M tokens あたり、Singapore リージョン、報道ベース)。weights は未公開。

Tencent Hy4 flash を公開

11/16 に Hy4 ファミリーの低価格・高速版を公開。総 224B / active 12B の MoE、1M token の context、multimodal 入力、デコード 150 tokens/s 超とされる。
価格は入力約 $0.07、出力約 $0.28(1M tokens あたり、報道ベース)で、Tencent はタスク当たりのコストが Hy4 の約1/20としている。open weight 化は予定のみで時期は未定。
