OpenAI / Anthropic / Google

ChatGPT の Chat と Work が1つの利用上限に、Pro の一部から開始(報道ベース)

11/25(米国時間)開始。OpenAI は ChatGPT の Chat と Work を1つの体験にまとめ、使用量も共通の上限で数える変更を、まず Pro の一部ユーザーで始めた。OpenAI の Thibault Sottiaux が X で告知した。サポートページによれば、共通の上限が広く適用されるのは12月の見込み。
Instant モデルの会話は共通の上限に数えず、上限に達したあとも使い続けられる。OpenAI の広報は「大半の契約者は上限に達する頻度は変わらないが、最もヘビーなごく一部は早く上限に達する可能性がある」とした。Chat と Work の配分、残量の見え方、リセットの頻度はまだ説明されていない。Pro 契約者からは「同じ料金で高度な推論モデルの使える量が減る」という反発が出ている。
ChatGPT で agent 系の作業(Work)を多く回している人は、12月以降の上限の数え方を確認しておく必要がある。この環境からは openai.com・help.openai.com・x.com に直接接続できないため、内容は TechCrunch などの報道で確認した(報道ベース)。
