Thinking Machines が open weight の Inkling 2 Mini を公開

11/20(米国時間)公開。総パラメータ約26B の MoE で、中間の12層を1トークンあたり3回繰り返す looped transformer(保存は24層、論理的には48層)。内部で多く推論する分、少ないトークンで答えに届くという設計。テキストと画像の入力、1M context、Apache 2.0。
weights は Hugging Face にあり、Tinker で推論・fine-tuning も可能。Ollama では 32GB 以上の Mac で動く。active パラメータは 3.4B〜5.4B と情報源で食い違う。事実の想起や細かい指示追従が弱く、デバッグ時に推論が繰り返しがちという制約を公式が挙げている。

Claude Code v2.1.330

11/20(UTC)公開。recurring の scheduled task と /loop が最大30日まで動くようになった(従来は7日、既存のタスクは7日のまま)。claude auth login 後に組織の設定とクラウドプロバイダー・gateway を自動で使う enterprise sign-in、chart を描く組み込みの easel mod(Pro・Max ほか、macOS・Linux)を追加。
root・home・作業フォルダなどを狙う rm は承認が必要になり、承認者がいない環境では拒否される。長い会話の compact 後のフリーズ、並行実行時の設定の消失、他セッションが使う worktree を消す不具合などを修正。2.1.329 で消した max_tokens 超過時の自動リトライは復活した。

米労働省が独立請負人の判定ルールを改定、2024年ルールを廃止

11/19(米国時間)発表。FLSA(公正労働基準法)などで従業員と独立請負人を分ける基準を改め、Biden 政権の2024年ルール(2025年5月から執行停止)を廃止して2021年ルールに近い形に戻した。
最も重視するのは「仕事に対する管理の度合い」と「自らの工夫・投資による損益の機会」の2要素。Federal Register 掲載の60日後に施行。税法や州法の判定には影響しないため、カリフォルニア州など厳しい州法のある地域では従来どおりの対応が要る。
