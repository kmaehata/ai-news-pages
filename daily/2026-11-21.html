OpenAI / Anthropic / Google

OpenAI が Dots を ChatGPT Plus の一部で試験提供、Business Standard にも拡大(報道ベース)

11/19(米国時間)発表。9月の DevDay で Pro・Business Premium 向けに出した常時稼働エージェント Dots を、$20/月の Plus の一部ユーザーで試験提供し始めた。対象はランダムに選ばれ、サポート経由で有効化はできない。EEA・英国・スイスは対象外。
Business Standard にも展開を始めたが、米国のユーザーに限るとする報道もある。Plus・Business Standard の利用上限は明らかにされていない。

開発手法・ツール

Codex CLI 0.171.0

11/19(米国時間)公開。GPT-6.2 Sol / Astra をモデル一覧に加え、Sol を既定にした。TUI workspace が既定で有効になり、文書・画像のプレビューや subagent の transcript を検索・表示できる。
codex exec --remote で既存の app server 上の非対話セッションを開始・再開でき、/rc・/remote でリモート操作とデバイスのペアリングを管理できる。/statusline で MCP の status line を作れる設定(tui_extensions_statusline)も追加。

Claude Code v2.1.329

11/19(米国時間)公開。/tasks に scheduled task、/loop の wakeup、goal、会話の fork が並び、x で止められる。フォルダの hooks がどこで宣言されているかを示す trust ダイアログを追加し、managed settings の hooks が読めないときは警告する。
/code-review は対象なしだとブランチ全体を既定ブランチと比べてレビューし、PR 番号指定では gh pr diff で実際の PR を読むよう修正。Code Mode のメモリ暴走やフリーズ、~/.claude.json が初期化される不具合なども多数修正。2.1.326 で入った max_tokens エラー時の自動リトライは削除された。
